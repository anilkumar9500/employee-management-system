# Employee Management System

A backend REST API application for managing employee information.

## 📌 Project Description

Employee Management System is a Spring Boot based backend application that provides REST APIs to manage employee records.

The application allows users to:

- Add new employees
- View all employees
- View employee by ID
- Update employee details
- Delete employees
- Manage employee information through REST APIs

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- REST API
- MySQL
- Gradle
- Git & GitHub
- Postman
